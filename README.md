# ClaudeCage 🛡️

**ClaudeCage** — защищённый Android-контейнер для веб-интерфейса [Anthropic Claude](https://claude.ai) с реализацией строгой архитектуры **Strict Fail-Closed Zero-Leak**.

Приложение создано для гарантированного предотвращения утечек реального сетевого окружения (IP-адреса, системных DNS, геолокации, часового пояса, системного языка и аппаратного фингерпринтинга) при работе через VPN (в частности, Amnezia VPN Premium).

---

## ⚡ Ключевые Возможности и Инварианты Безопасности (Stage 9 Hardening)

- **100% SOCKS5 Proxy Override:** Полная изоляция движка Chromium WebView через локальный шлюз `127.0.0.1:<ephemeral_port>`. Любой прямой выход в интернет (`direct://`) аппаратным образом запрещён.
- **Привязка сокетов на уровне ядра (Kernel Socket Binding):** Все исходящие TCP-сокеты шлюза и DNS-резолвера сначала привязываются к NetID VPN (`Network.bindSocket`), а затем к IPv4-адресу tun-интерфейса (`socket.bind`).
- **Мгновенный аппаратный Kill-Switch:** При малейшем сбое или отключении VPN все активные дескрипторы сокетов принудительно разрываются (`closeAllActiveSockets()`). Ни одного байта не может уйти через обычный Wi-Fi или сотовую связь.
- **Fail-Closed TCP DNS (RFC 1035):** Системные DNS и сторонние Smart DNS полностью игнорируются. Резолвинг происходит строго внутри туннеля через TCP (`1.1.1.1:53` $\to$ `8.8.8.8:53`).
- **Защита от Doze Mode (Socket Watchdog & Stale-Cache):** Неблокирующий сторожевой таймер прерывает зависшие вызовы сокета ядра Linux через 2.5 секунды при выходе телефона из сна. Реализован механизм Stale-While-Revalidate для мгновенного восстановления связи.
- **Региональный фильтр доменов (Regional Domain Guard):** Прозрачный rewrite `.google.ru` $\to$ `.google.com`. Домены СНГ (`.ru`, `.su`, `.by`, `.рф`) мгновенно блокируются с возвратом `0x05 (Connection Refused)`. IPv6 (`ATYP 0x04`) отклоняется ответом `0x08`.
- **Многопрофильная контейнеризация (Multi-Account):** Изолированное хранение сессий для каждого аккаунта через AndroidX `ProfileStore` (или резервный CookieJar с аппаратным шифрованием `AndroidKeyStore` AES-256-GCM).
- **Глубокий спуфинг фингерпринта (Anti-Fingerprint Hardening):**
  - WebRTC полностью ампутирован на уровне Document-Start JS.
  - Детерминированный Canvas-шум для всех профилей (перехват `getImageData`, `toDataURL`, `toBlob`).
  - Блокировка системных русских голосовых пакетов (`speechSynthesis.getVoices = () => []`).
  - Фиксация всех конструкторов `Intl.*` на локаль `en-US`.
  - Спуфинг POSIX TZ (`Europe/Amsterdam`), `LocaleList.setDefault(Locale.US)`, `navigator.webdriver = false`.
- **Современный UI / UX:**
  - Плавающий перемещаемый якорь безопасности с индикатором состояния: 🟢 (Защищено), 🟡 (Amber: туннель не отвечает), 🔴 (Сеть заблокирована).
  - Карточная панель диагностики и версий компонентов.
  - Безопасная загрузка файлов и артефактов Claude через JS-Bridge (`SafeDownloadBridge`).
  - Защита снимков экрана в списке недавних приложений (`FLAG_SECURE`).

## 🛠️ Сборка Проекта

### Требования:
- Android SDK (API 33–36+)
- JDK 17+
- Gradle 9+ (включён Gradle Wrapper)

### Команды:

```bash
# Запуск полного набора модульных тестов
./gradlew testDebugUnitTest

# Сборка Debug APK
./gradlew assembleDebug

# Полный цикл: тесты + сборка APK
./gradlew testDebugUnitTest assembleDebug
```

> [!NOTE]
> Собранный APK автоматически именуется и сохраняется **прямо в корень проекта**:
> `ClaudeCage-1.0.apk`
